How to use this manual

  1. Open the program and read Concepts in brief.
  2. Follow the numbered steps in Tally Prime. Tap a step to fold or open it.
  3. Tick Mark this step as done. Your ticks are saved on this device.
  4. Compare your figures with the You should see notes and the Checkpoint before moving on.
Shortcut keys differ slightly between Tally Prime releases. If a shortcut does not respond, press Alt + G (Go To), type the screen name and press Enter.
Quick reference: common keys
Key Action
Enter Accept a field / move on
Ctrl + A Accept (save) a screen or voucher
Esc Go back / cancel
Alt + G Go To any screen
F2 Change period or date
Alt + D Delete (inside Alter screen)
F4 F5 F6 F7 Contra, Payment, Receipt, Journal
F8 F9 Sales, Purchase
Ctrl + F8 Ctrl + F9 Credit Note, Debit Note
F1 / Alt + F1 Select / Shut company
Alt + K / Alt + Y Company menu / Data menu
