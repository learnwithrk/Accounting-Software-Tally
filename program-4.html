Program 4: Recording Transactions and Trial Balance

Create ledgers, pass 14 vouchers and agree your Trial Balance with the given one.

Tally PrimeIntermediateAbout 60 min
After this program you will be able to:
  1. Create ledgers for a full set of accounts using multiple ledger creation.
  2. Convert a list of year-end balances into a small set of correct vouchers.
  3. Use Journal, Purchase, Sales, Debit Note, Credit Note, Receipt, Contra and Payment vouchers.
  4. Verify the Trial Balance against a given Trial Balance.

Rule. Pass every entry only through the voucher type named in its step. The Journal voucher is used for the opening entry and for entries that involve neither cash, bank, a purchase nor a sale (vouchers 7, 8 and 9).

Steps

1Create a fresh company
  1. Press Alt + K -> Create and create a new company. Use a new company so the April data of Programs 1 to 3 is not mixed with this exercise.
Field Enter
Name Mayura Traders (Final Accounts)
Financial year beginning from 01-04-2026
Books beginning from 01-04-2026
Maintain Accounts Only
Base currency symbol ₹
  1. Press Ctrl + A to accept. Refer to Program 1 for the other fields.
  2. Press F2 (Period) and set From 01-04-2026, To 31-03-2027.
You should see: Mayura Traders (Final Accounts) in the Gateway title bar.
2Create all ledgers at once
  1. Alt + G -> Chart of Accounts -> Ledgers -> Alt + H (Multi-Masters) -> Multi Create.
  2. For each block choose Under, then type the names in the Name column. Leave opening balances blank (the opening entry is passed as voucher 1).
Under Ledger names
Capital Account Capital A/c; Drawings
Fixed Assets Goodwill; Buildings; Machinery; Furniture
Current Assets Bills Receivable
Bank Accounts Bank A/c
Cash-in-Hand Cash
Sundry Debtors Debtors
Sundry Creditors Creditors
Current Liabilities Bills Payable
Purchase Accounts Purchases; Purchase Return
Sales Accounts Sales; Sales Return
Direct Expenses Opening Stock; Wages; Carriage Inward
Indirect Expenses Carriage Outward; Salary; Rent; Discount Allowed; Repairs; Bad Debts; Advertisement; General Expenses
  1. Press Ctrl + A to accept.

Why Opening Stock sits under Direct Expenses. It is a debit item of the Trading Account, so it is grouped with the direct expenses. This also keeps the stock figure easy to read in Program 10.

You should see: 27 ledgers listed under their groups. Check the count against the Trial Balance.
3Voucher 1: Journal (opening entry)
  • Voucher / key / date: Journal, F7, 01-04-2026.
  • Enter these lines, choosing Dr or Cr for each:

  • Check: total Dr = total Cr = ₹2,36,000.
4Voucher 2: Purchase (credit purchase)
  • Voucher / key / date: Purchase, F9, 15-04-2026. Use Accounting Invoice mode (Ctrl + H).
  • Party A/c name: Creditors. Ledger: Purchases, 51,000.
  • Journal entry: Purchases Dr 51,000; To Creditors 51,000.
5Voucher 3: Sales (credit sale)
  • Voucher / key / date: Sales, F8, 30-04-2026, Accounting Invoice mode.
  • Party A/c name: Debtors. Ledger: Sales, 1,00,000.
  • Journal entry: Debtors Dr 1,00,000; To Sales 1,00,000.
6Voucher 4: Debit Note (purchase return)
  • Voucher / key / date: Debit Note, Ctrl + F9, 15-05-2026.
  • Party A/c name: Creditors. Ledger: Purchase Return, 2,600.
  • Journal entry: Creditors Dr 2,600; To Purchase Return 2,600.
7Voucher 5: Credit Note (sales return)

  • Party A/c name: Debtors. Ledger: Sales Return, 2,000.
  • Journal entry: Sales Return Dr 2,000; To Debtors 2,000.
8Voucher 6: Sales (cash sale)
